## 安裝與連線

當前預覽版本為 0.1.10，可本地構建，或從成功的 [Android 工作流](https://github.com/hanfdev/mihonban/actions/workflows/android.yml)下載 debug APK。release APK 需要使用自己的金鑰簽名。填寫伺服器根地址，例如 `https://music.example.com` 或 `http://192.168.1.20:8788`，並輸入聽眾或管理員口令；僅在伺服器允許訪客訪問時留空。Android 模擬器可透過 `http://10.0.2.2:8788` 訪問宿主電腦的開發伺服器。手機訪問電腦時使用電腦的區域網 IP；手機的 `localhost` 指向手機自身。

遠端伺服器建議使用 HTTPS。現有 Node/Wrangler 開發模式支援本地 HTTP，但伺服器必須設定 `DEV_INSECURE_COOKIE=1` 才能使用 HTTP 會話 Cookie。應用不會跳過 TLS 證書驗證。

## 原生功能

- 專輯網格、歌曲列表、風格篩選、年份／標題／藝人／評分／最近加入排序、全庫搜尋、多藝人署名與藝人作品頁。
- 專輯詳情、評分、簡介、相關專輯、內頁翻閱與雙指縮放、Android 分享面板，以及共享的專輯和歌曲精選。
- 迷你播放器、完整播放器、進度拖動、隨機、迴圈、可編輯佇列、下一首播放、睡眠定時、音訊焦點與耳機斷開處理。
- Media3 前臺播放服務，支援通知、耳機和鎖屏控制。介面進入後臺後繼續播放；程序重啟後恢復處於暫停狀態的佇列。
- WorkManager 將下載儲存到應用私有儲存，提供進度、暫停／重試／刪除、校驗後的位元組範圍續傳、持久化資料和專輯封面、離線播放與快取曲庫瀏覽。
- 管理員可編輯專輯／歌曲／藝人、調整可見性、確認後刪除、匯入 Discogs 後設資料和內頁、重排圖片、透過 Android 檔案選擇器上傳音訊、掃描並登記伺服器資料夾。
- 伺服器管理包括訪客訪問與模組設定、命名儲存配置／測試／寫入目標、R2 配置和測試、來源收件箱與掃描，以及聽眾／管理員口令修改。
- 沿用 Web 的黑褐底色、暖米白文字、硃紅強調色和襯線標題；觸控目標、底部導航、滾動位置恢復、系統返回、旋轉和安全區使用原生 Compose 行為。

曲庫直接進入專輯或歌曲。向上滾動收起頂部欄，向下滾動恢復。網格密度可切換，風格和排序放在可關閉的底部面板。搜尋提供現有風格、最近加入專輯和結果分類。專輯詳情將封面與資料並排，次要操作集中在選單中。標籤頁狀態按伺服器和訪問身份分別儲存。最近加入按專輯首次入庫時間排序，修改評分或其他資料不會讓舊專輯排到最前。

0.1.3 將內嵌簡介展開替換為獨立閱讀頁。專輯頁保留三行純文字摘要；閱讀頁標題和關閉按鈕固定，支援回到頂部，關閉時恢復專輯位置，再次開啟時保留閱讀進度。CommonMark 與 GFM 表格／刪除線原生渲染，支援文字選擇、巢狀列表、引用、連結、程式碼、分隔線和獨立圖片；寬表格與程式碼橫向滾動。原始 HTML 作為文字顯示。配色和字型沿用 Web，不使用 WebView。

0.1.4 為簡介圖片增加載入反饋、可讀替代文字和“重新載入圖片”按鈕，避免失敗時只有空白。重試只重新載入該圖片，閱讀頁保持開啟。不可用地址會顯示說明，不提供無效重試。

0.1.5 修復只有一個長段落或引用塊時的“回到頂部”：現在計算 Markdown 塊內部滾動，並在回到開頭時隱藏按鈕。標題字型在 Activity 重建之間共享，避免重複分配內建字型緩衝區。

0.1.6 在 WorkManager 任務停止時取消活動下載請求，包括伺服器尚未返回響應頭或在響應體中卡住的情況。暫停或刪除下載無需等待網路超時。封面下載採用相同取消處理。手動重試從頭開始，自動重試可繼續經過校驗的部分資料。

0.1.7 讓與文字或說明共處一段的簡介圖片正常顯示。文字和圖片按原文順序排列，保持可讀間距，巢狀引用也適用；周圍文字保留 Markdown 格式，圖片保留載入反饋和重試操作。

0.1.8 將豎屏播放控制上移並拉近封面與標題。在底部增加當前歌曲下載、分享、佇列快捷欄。下載提供進度和暫停／重試，已完成下載保持完整。分享透過 Android 面板傳送歌名、藝人和 Web 專輯連結。橫屏將快捷欄放在封面下方，為歌曲資料留出空間。完整播放器資料區仍只顯示標題和藝人。

0.1.9 預設按加權評分排列專輯，使用與 Web 相同的置信度調整和同分排序規則。點選專輯的主風格或次風格會開啟按此規則排序的匹配專輯，返回時回到原專輯。收起頂部欄後完整裁去標題和圖示，保留系統狀態列區域。

0.1.10 修復頂部欄幾乎收起時殘留的標題／圖示碎片：完整高度的欄整體滑出，而非把控制元件居中擠在縮小的窄條內；使用實際測量的收起距離，並在末段淡出。顯示縮放變化後仍保持收起位置。狀態列留白位於滑動行之外。

“我的 → 播放設定”提供下一首預載入：僅 Wi-Fi（預設）、始終開啟和關閉。僅 Wi-Fi 模式在預設網路切換到移動資料時取消預載入，回到 Wi-Fi 後恢復。隨機播放時跟隨實際下一首，等待當前歌曲緩衝後開始，跳過已下載歌曲，暫停時停止。最多將下一首的前 16 MiB 放入現有的伺服器／身份隔離音樂快取，受其容量上限約束，播放時複用這些位元組。這是裝置偏好，不需要管理員許可權。

320–599 dp 的手機明確切換兩列／三列，更窄視窗和平板也使用不同列數。網格按鈕為無數字、無強調色的中性圖示，讀屏仍會播報當前列數。偏好跨重啟儲存，曲庫、精選和風格頁共用。曲庫支援下拉重新整理。佇列開啟時定位當前歌曲，返回鍵回到播放器，清空佇列需確認。

0.1.2 將播放控制保持在可用安全區內，封面隨剩餘空間縮放。資料區僅顯示歌名和藝人，點選標題開啟專輯；緩衝時保留可操作的播放／暫停圖示。歌曲列表的隨機按鈕只切換選擇狀態，按“播放全部”後才啟動或改變播放；專輯詳情的隨機按鈕直接播放該專輯。

“我的 → 快取設定”顯示音樂／圖片磁碟佔用，提供 128 MB～2 GB 的音樂快取上限及自動音樂／圖片快取清理。降低上限會立即淘汰較舊音樂資料；圖片獨立限制為 64 MB。主動下載、已存曲庫和登入狀態保留，活動播放可能生成新快取。流快取鍵包含伺服器和訪問身份。

精選是伺服器共享的人工選集：與 Web 一樣，聽眾和訪客只讀，僅管理員可修改。伺服器地址、曲庫快照、圖片和下載按伺服器及訪問身份隔離。會話 Cookie 使用 Android Keystore AES-GCM 加密儲存，不儲存口令。應用資料不參加 Android 備份。

## 構建與測試

需要 JDK 17、Android SDK platform 35 和 Build Tools 35.0.0。可用 Android Studio 開啟本目錄，或在倉庫根目錄執行：

```powershell
android\gradlew.bat -p android testDebugUnitTest lintDebug assembleDebug assembleRelease
android\gradlew.bat -p android connectedDebugAndroidTest
```

macOS/Linux：

```sh
sh android/gradlew -p android testDebugUnitTest lintDebug assembleDebug assembleRelease
sh android/gradlew -p android connectedDebugAndroidTest
```

透過 `ANDROID_HOME` 或忽略的 `android/local.properties` 中的 `sdk.dir` 指定 SDK。包裝指令碼固定 Gradle 8.9。測試無需生產伺服器、憑據或音訊。JVM 測試覆蓋 JSON 相容、URL／Cookie 隔離、重定向安全和下載範圍驗證；裝置測試透過內嵌 HTTP 測試服務和合成 PCM 音訊驗證原生導航、播放、拖動、佇列、下載及離線播放。

輸出：

- 可安裝開發 APK：`app/build/outputs/apk/debug/app-debug.apk`。
- 未簽名釋出 APK：`app/build/outputs/apk/release/app-release-unsigned.apk`。分發前使用自己的釋出金鑰簽名，並保留該金鑰用於後續更新。
- JVM 與 lint 報告：`app/build/reports/`。

Android GitHub Actions 工作流構建兩種變體並執行 JVM／lint 檢查，另有 API 35 模擬器任務；不會自動釋出版本或使用生產金鑰簽名。

驗證命令、歷史結果和裝置覆蓋範圍見[驗證記錄](VERIFICATION.zh-Hant.md)。代表性文件截圖儲存在 `docs/images/`；APK、完整截圖集和構建報告仍是生成產物，不隨原始碼提交。CI 產物需要訪問對應工作流，並按 GitHub 保留設定過期。

## 當前邊界

格式支援取決於 Media3 和裝置解碼器，包括常見 MP3、FLAC、AAC、WAV、Vorbis 和 Opus；未內建 DSD/APE 等專用編解碼器。手機上傳可跨旋轉繼續，但屬於前臺編輯操作，登記完成前須保持應用開啟，尚不是持久後臺上傳佇列。若登記前取消，可能需在儲存服務中清理已上傳的部分檔案。

主聽歌介面隨裝置語言提供中英文，管理介面目前為簡體中文。瀏覽器輔助 RYM 更新及儲存的 HTML 匯入、完整配置備份／恢復、批次儲存遷移和儲存 OAuth 設定仍在 Web 中完成。本客戶端連線現有伺服器，不託管伺服器。

專案使用倉庫的 AGPL-3.0-only 許可證；第三方依賴保留各自許可證。內建 Shippori Mincho 與 GenRyu Mincho 和 Web 使用相同字型，SIL Open Font License 文字位於 `app/src/main/assets/licenses/`。
