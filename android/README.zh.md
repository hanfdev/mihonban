# Mihonban 原生 Android 客户端

使用 Kotlin、Jetpack Compose 和 Media3 开发，支持 Android 8.0 及以上。所有页面和播放功能均为原生实现，无 WebView。

## 安装与连接

1. 当前预览版本为 0.1.10，可自行构建，或从成功的 [Android 工作流](https://github.com/hanfdev/mihonban/actions/workflows/android.yml)下载 debug APK。自行构建时默认输出为 `app/build/outputs/apk/debug/app-debug.apk`；release APK 需要自行签名。版本可在“我的”页面确认。
2. 填写现有 Mihonban 服务器地址，例如 `https://music.example.com` 或 `http://192.168.1.20:8788`。
3. 输入听众或管理员口令；服务器启用访客访问时可留空。管理员口令会解锁管理功能。

手机访问电脑上的服务器时，请填写电脑的局域网 IP；手机的 `localhost` 指向手机自身。Android 模拟器访问电脑时可使用 `http://10.0.2.2:8788`。本地 HTTP 服务器需要配置 `DEV_INSECURE_COOKIE=1`；远程服务器建议使用 HTTPS。

## 已实现

- 曲库：专辑网格、歌曲列表、风格筛选、名称/艺人/年份/评分/最近加入排序、全库搜索。
- 详情：多艺人署名及跳转、艺人作品与合作歌曲、专辑评分、备注、相关专辑、内页翻阅与双指缩放、系统分享。
- 精选：与 Web 端共享的专辑和歌曲精选；管理员编辑，听众及访客只读。
- 播放：迷你播放器、全屏播放器、拖动进度、上一首/下一首、随机/循环、插队/排序/移除、睡眠定时。
- 系统集成：后台播放、锁屏与通知栏控制、耳机按键、音频焦点和拔出耳机自动暂停；重启后恢复暂停状态的队列。
- 离线：后台下载、进度、暂停/重试/删除、校验后的断点续传、音频与封面保存、缓存曲库浏览和断网播放。
- 下载取消：服务器迟迟不响应或传输中卡住时，暂停／删除会取消对应网络请求，无需等网络超时。自动重试支持经过校验的断点续传，手动重试会重新下载。
- 缓存：“我的 → 缓存设置”可调整音乐缓存上限（128 MB～2 GB），查看音频与图片占用、清除临时缓存。图片缓存上限为 64 MB，主动下载的歌曲和已保存曲库不受清理影响。
- 导入：Android 文件选择器选择音频、读取标签、上传并登记专辑；扫描服务器存储中的文件夹。
- 管理：编辑专辑/曲目/艺人、隐藏专辑、确认后删除、Discogs 流派及图片导入、封面与内页管理。
- 服务设置：访客访问、存储配置与测试、上传主存储、R2 图片镜像、资源站扫描与状态、修改口令。

界面沿用 Web 端的黑褐底色、米白文字、朱红强调色、唱片标识和衬线字体，采用底部导航、整行点击、原生返回、滚动位置恢复和系统安全区。

0.1.7 修复简介图片与说明文字写在同一段时只显示文字链接的问题：现在按原文顺序显示文字、图片和说明，保留加粗等 Markdown 格式，嵌套引用内也适用。图片继续支持加载提示和失败重试。

0.1.8 将竖屏播放键上移，拉近封面与歌名的距离，并在底部增加当前歌曲的下载、分享和队列快捷栏。下载可查看进度、暂停和重试；已下载状态不会误删离线文件。分享通过系统面板分享歌名、歌手及 Web 专辑链接。横屏将快捷栏放在封面下方，给歌曲信息和播放控制保留空间。

0.1.9 首页专辑默认按加权评分排序，与 Web 端使用相同算法。点击专辑的主风格或次风格标签，会打开所有同风格作品，返回时回到原专辑。上滑收起顶部栏后，标题与搜索、刷新图标完全隐藏，系统状态栏区域正常保留。

0.1.10 进一步修复顶部栏接近收起时仍露出标题和图标碎片的问题：现在整条栏按实际测量高度向上移出，收起末段淡出，不再把图标挤在剩余的窄条里。调整显示缩放后也保持收起状态，系统状态栏留白独立保留。

“我的 → 播放设置 → 下一首预加载”提供“仅 Wi-Fi”（默认）、“始终开启”和“关闭”。仅 Wi-Fi 模式在切换到移动网络时取消预加载，回到 Wi-Fi 后自动恢复；随机播放时跟随队列里实际的下一首。当前歌曲缓冲充足后才提前加载，最多缓存下一首前 16 MiB，复用现有音乐缓存与容量上限；已下载歌曲跳过，暂停播放时停止预加载。这是设备本地设置，听众和管理员均可调整。

### 紧凑界面

- 首页直接展示专辑和歌曲，不再放置宣传标题。向上滚动收起顶部栏，向下滚动恢复；内容分类和底部导航保持可用。
- 右上角网格按钮仅显示中性色图标，不显示数字、不变为橙红色；读屏仍可播报当前列数。点击切换舒展／紧凑密度。320–599dp 宽的手机明确切换两列／三列，更窄窗口与平板也使用不同列数。选择在曲库、精选和风格页共用，重启后保留。
- 风格与排序位于可关闭的底部面板，已选风格可一键清除；曲库支持下拉刷新。
- 搜索页提供曲库现有风格和最近加入的专辑；搜索后可按专辑、歌曲、艺人缩小结果范围。
- 专辑详情采用封面与资料并排的布局，简介保留三行纯文本摘要，点击“阅读全文”进入独立阅读页。标题和关闭按钮始终固定，正文单独滚动，可一键回到顶部；关闭后回到专辑原位置，再次打开保留阅读进度。
- 长文即使只有一个段落或一整块引用，滚动后也会显示“回到顶部”；回到开头后按钮自动隐藏。
- 简介全文原生渲染 Markdown 标题、粗体、斜体、删除线、有序／无序及嵌套列表、引用、链接、代码块、分隔线、表格和独立段落图片；表格与代码可横向滚动，文字可选中复制。原始 HTML 作为文本显示，不执行。
- 简介图片显示加载状态；加载失败时保留图片说明，并可直接“重新加载图片”，无需退出阅读页。无效图片地址会显示提示。
- 分享、编辑及内页管理集中在专辑操作菜单中。
- 切换底部标签会保留筛选、密度、搜索和列表位置；页面状态按服务器及访问身份隔离。
- 歌曲列表的随机按钮只切换点亮／关闭状态，点击“播放全部”才按所选模式播放。专辑详情的随机播放立即播放该专辑，播放器里的随机按钮控制当前队列。
- 播放器资料区只显示歌名和歌手，点击歌名进入所属专辑；控制区固定在底部安全区域，封面随可用空间缩放，长标题不会挤走按钮。缓冲时保留可点击的播放／暂停图标。
- 队列默认定位到当前歌曲，返回键先回到播放器，清空前需要确认。歌曲菜单保留下载入口，已下载歌曲有离线标识。

会话使用 Android Keystore 加密保存，不保存口令。曲库、图片和下载按服务器及权限分开，退出登录会停止播放。应用数据不参加系统备份或设备迁移。

## 构建

需要 JDK 17、Android SDK 35 和 Build Tools 35.0.0。在正式仓库根目录运行：

```powershell
android\gradlew.bat -p android testDebugUnitTest lintDebug assembleDebug assembleRelease
android\gradlew.bat -p android connectedDebugAndroidTest
```

也可以使用 Android Studio 打开 `android/`。通过 `ANDROID_HOME` 或未纳入版本控制的 `android/local.properties` 指定 SDK。

发布版输出为 `app/build/outputs/apk/release/app-release-unsigned.apk`，需要使用自己的长期发布密钥签名后分发。GitHub Actions 已配置构建和模拟器测试，不会自动发布商店版本。APK、截图和报告属于生成产物，不随源代码提交；工作流产物需要对应访问权限，并会按保留设置过期。

## 当前边界

- 已在 Android 15 模拟器验证，尚未覆盖所有品牌实体手机及 Android 8.0 设备。
- 主听歌界面随系统语言提供中英文；管理界面目前为简体中文。
- 常见 MP3、FLAC、AAC、WAV、Vorbis、Opus 由 Media3 和设备解码器支持，未内置 DSD/APE 等专用解码器。
- 手机上传可跨屏幕旋转继续，但上传完成前需要保持应用运行；尚不是可跨进程恢复的后台上传队列。
- 浏览器辅助 RYM 更新及保存的 HTML 导入、完整配置备份/恢复、批量存储迁移和存储 OAuth 授权仍使用 Web 端。
- 验证使用隔离的测试服务器和合成音频；OneDrive/WebDAV/Google Drive 实际账户及生产曲库尚需部署环境联调。
