# ネイティブクライアントの互換性契約

[English](API_COMPATIBILITY.md) · [简体中文](API_COMPATIBILITY.zh.md) · [繁體中文](API_COMPATIBILITY.zh-Hant.md) · [日本語](API_COMPATIBILITY.ja.md) · [한국어](API_COMPATIBILITY.ko.md) · [Français](API_COMPATIBILITY.fr.md) · [Español](API_COMPATIBILITY.es.md)

ネイティブクライアントは `cloud/web` とは別のアプリです。以下の API の互換性を維持すれば、Mihonban サーバーは Web 画面を変更して独立にデプロイできます。

## セッションとライブラリ

クライアントはリクエスト間でセッション Cookie を保持します。設定されたゲストセッションならパスワードなしで閲覧でき、保護された環境ではログインが必要です。非表示アルバムと共有お気に入りの変更にはサーバーの権限制御が適用されます。

- `GET /api/health` は成功レスポンスを返します。
- `GET /api/me` は現在のセッションオブジェクトを返します。`401` の場合はパスワード入力へ進みます。
- `POST /api/login` は `{ "password": "..." }` を受け取り、`{ "ok": true, "role": "user|admin" }` を返します。
- `GET /api/library` は閲覧可能なアルバムの配列を返します。
- `GET /api/tracks` は閲覧可能な曲の配列を返します。
- `GET /api/album/:id` は `tracks` 配列を含むアルバムオブジェクトを返します。
- `GET /api/artists` はアーティスト情報を返します。
- `GET /api/favorites` は `albums` と `tracks` の配列を含むオブジェクトを返し、各項目に `id` を持ちます。
- `PUT /api/favorites/:kind/:id` は共有お気に入りを追加し、同じパスの `DELETE` は削除します。`kind` は `album` または `track` です。書き込みには管理者権限が必要です。

権限を持つ管理者はアルバムと曲の一覧に `?hidden=1` を付けられます。アルバム詳細には `note`、`images`、`similar` が含まれることもあります。パス内のアーティスト名と項目 ID は URL エンコードします。

## 画像と音声

- `GET /api/art/:albumId?s=480` は画像本体を返します。
- `GET /api/image/:id?s=:size` はアルバムのギャラリー画像を返します。
- `GET /api/artist-bio/:name` は `bio` 文字列を含むオブジェクトを返します。
- `GET /api/artist-art/:name` はアーティスト画像を返します。カスタム画像の場合は `?v=c` を付けます。
- `GET /api/stream/:trackId` は元の音声バイト列、またはその音声に到達するリダイレクトを返します。

デスクトップクライアントは完全な音声ファイルをダウンロードし、ローカルでデコードとシークを行います。Web プレーヤーのストリーミング配置には依存しません。画像は一つの応答につき 32 MiB までです。正確なパスとデシリアライズ時の既定値は [`src/api.rs`](src/api.rs) を参照してください。

## 互換性とクライアント更新

クライアントは未知の JSON フィールドを無視し、モデルで任意とされるフィールドには既定値を用います。アルバム ID、アーティスト名、タイトルなどの必須項目は互換性のある型を保つ必要があります。未知のフィールドを追加できることは、既存の必須項目を省略できることを意味しません。クライアントは Mihonban のデータベース、ストレージ認証情報、デプロイファイルにアクセスしないため、この API 契約の範囲内でサーバー移行、保存先、クライアントのリリースを独立して変更できます。

クライアントのリリースには、`latest`、`download_url`、`sha256`、`notes` を含む独立した JSON マニフェストを利用できます。SHA-256 を必ず公開してください。現在のクライアントがチェックするのは、このフィールドが空でない場合だけです。ダウンロード後は手動の exe 置換用に準備し、自動インストールやサーバー更新は行いません。設定、ビルド、再生は[デスクトップガイド](README.ja.md)を参照してください。
